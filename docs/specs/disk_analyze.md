# 磁盘分析页（disk_analyze）

- 来源 task：t006、t020、t028、t032、t052
- 生效范围：磁盘页（应用内只读扫描；不调用 mole）
- 最后更新：2026-10-18

## 行为契约

- 磁盘页在应用内只读遍历目录（`lstat`）；打开、下钻、返回与重新分析都不调用 `analyze` 命令。
- 磁盘测量由单一测量会话服务 `DiskMeasurementSession` 调度，ViewModel 只负责浏览需求与呈现。
- 文件大小取 `st_blocks × 512`；符号链接只计链接自身；同一统计范围内的硬链接只计一次；兄弟目录间共享 inode 按规范化路径排序确定归属，不因并发完成顺序变化；独立目录自身合计与父范围去重贡献分别命名和独立计入；设备号与父目录不同的子目录标记 `.otherDevice` 不计入父合计（进入后单独计算）；无法读取的目录标「未扫描」，不显示为 0。
- 进入目录先列出直接子项与直接文件大小；子目录大小由会话队列在后台补上（最多 3 路并发，队列非空持续消费，无待测与在途时结束忙碌）。大小未知的目录显示「计算中」，不计入合计与面积图。
- 进入正在测量的祖先目录下的子目录时，复用该祖先在途遍历，不产生重复子树请求；祖先遍历完成后，所有等待行（含当前层与展开层）均进入确定终态，不因较新 listing 导致卡在计算中。
- 某目录测量完成后，进入其子目录立即展示当时快照；「重新分析」创建新世代重扫当前子树并替换结果，取消旧请求且迟到结果不污染新世代。会话缓存有容量上限（4000 层），避免大树内存无界。
- 左列表与右方块图间分隔可拖动；列表行双击目录进入（文件不进入）；方块图双击目录进入。
- 列表行目录左侧提供展开箭头：点击原地展开/折叠子项（缩进区分层级，可任意深度），不改变当前目录、面包屑与选中；子项按当前排序参与行序，再次展开复用会话缓存，不重新列举。重新分析清除当前子树的展开状态。
- 列表行显示文件大小与「占当前目录百分比」列：所有行（含展开的后代行）统一以当前浏览目录的合计为分母 = 该项字节 ÷ 当前目录合计；当前层直接子项之和为 100%（未扫描、跨设备、计算中项除外），展开的后代行不重复计入该 100%，其百分比之和等于所属祖先项占当前目录的比例。方块图面积仍只按当前层占比绘制。
- 比例计算与排序为纯函数；列表排序/筛选结果按层版本缓存，测量发布不触发全量重排。
- 列表/选中/双击手势：按名称或大小排序不改变各项字节；搜索只过滤可见行名称，不改变选中。
- 列目录失败时保留上一层内容并显示错误条（不整页清空）。
- 页面不存在删除或移入废纸篓控件。
