# 磁盘分析页（disk_analyze）

- 来源 task：t006、t020、t028、t032
- 生效范围：磁盘页（应用内只读扫描；不调用 mole）
- 最后更新：2026-10-17

## 行为契约

- 磁盘页在应用内只读遍历目录（`lstat`）；打开、下钻、返回与重新分析都不调用 `analyze` 命令。
- 文件大小取 `st_blocks × 512`；符号链接只计链接自身；同一扫描内指向同一文件的硬链接只计一次；设备号与父目录不同的子目录不计入父合计（进入后单独计算）；无法读取的目录标「未扫描」，不显示为 0。
- 进入目录先列出直接子项与直接文件大小；子目录大小后台补上（最多 3 路并发，测量可随刷新取消）。大小未知的目录显示「计算中」，不计入合计与面积图。
- 某目录测量完成后，进入其子目录立即展示当时快照；「重新分析」重扫当前子树并替换结果。会话缓存有容量上限（4000 层），避免大树内存无界。
- 左列表与右方块图间分隔可拖动；列表行双击目录进入（文件不进入）；方块图双击目录进入。
- 列表行目录左侧提供展开箭头：点击原地展开/折叠子项（缩进区分层级，可任意深度），不改变当前目录、面包屑与选中；子项按当前排序参与行序，再次展开复用会话缓存，不重新列举。重新分析清除当前子树的展开状态。
- 列表行显示文件大小与「占父目录百分比」（= 该项字节 ÷ 所属父目录合计，顶层项取当前层合计；父目录合计仍计算中时显示占位）；方块图面积占比与之一致。
- 比例计算与排序为纯函数；列表排序/筛选结果按层版本缓存，测量发布不触发全量重排。
- 列表/选中/双击手势：按名称或大小排序不改变各项字节；搜索只过滤可见行名称，不改变选中。
- 列目录失败时保留上一层内容并显示错误条（不整页清空）。
- 页面不存在删除或移入废纸篓控件。
