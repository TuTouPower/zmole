# 空闲预跑（prewarm）

- 来源 task：t031
- 生效范围：应用空闲时的后台只读扫描
- 最后更新：2026-10-17

## 行为契约

- 无写入租约且无用户可见扫描（含磁盘页扫描与正在查看的清理预览/确认框）时，按固定顺序各跑一次：卸载名单、安装包名单、`clean --dry-run`、`optimize --dry-run`、`purge --dry-run`；任意时刻只有一个在跑。
- 预跑不获取写入租约；预跑进行中用户可以开始写入，写入开始时预跑被取消（取消为异步，clean 项写入前会等待取消完成）。
- 预跑只跑 `--dry-run`/只读形态：不 spawn 无 `--dry-run` 的 clean/optimize，也不 spawn `purge --yes`。
- 完成后打开对应页面不重新发起该扫描，并显示扫描时间；写入成功后全部预跑结果作废，回到空闲再跑一遍；确认框显示期间新结果不替换正在确认的那一份。
- 用户重新扫描某一项时取消当前预跑并把该项交给用户扫描；失败的项跳过继续、下一次空闲重试；被「活跃清理预览」推迟的 clean 项在预览关闭后重新入队（不因页面无新活动而永久搁置）。
- 活动变化通知经 200ms 窗口合并，避免扫描期高频发布造成任务风暴。
- demo 模式不启动预跑。
