# 应用外壳与导航（app_shell）

- 来源 task：t001、t003、t015、t014（由 t015 取代）、t035
- 生效范围：窗口结构、侧边栏、命令面板、三语、页面外壳
- 最后更新：2026-10-17

## 行为契约

- 采用标准窗口 App（SwiftUI，macOS 13+，Universal）；启动进入概览页。窗口默认 1200×780，最小 1100×700；保留系统标题栏与交通灯，内容区不绘制交通灯。
- 侧边栏两个分组共十个目的地：工作区（概览、清理、卸载、磁盘、优化、状态、项目清理、安装包）、系统（历史、设置）；当前项有可见选中态。系统菜单的「设置」打开侧边栏设置页。
- ⌘K 命令面板按页面名称过滤并跳转；面板内不存在会触发清理、卸载、优化、项目清理或安装包执行的动作（行类型只承载目的地）。
- 侧边栏品牌名为 zmole（不用 Mole 商标）。
- zh-Hans / zh-Hant / en 三语覆盖全部界面文案；默认跟随系统，设置页可覆盖并即时生效（含 locale 与外观）。
- 无菜单栏常驻项；关闭最后一个窗口即退出进程。
- 页面外壳统一：页头为 eyebrow + 标题 + 副标题 + 右侧动作区（共享 `MolePageHead`）；窗口工具栏不重复承载页面动作。优化、项目清理页的预览/取消动作位于页头动作区。
- 破坏性确认：预览成功后显示本次影响范围摘要，确认 sheet 使用具体动作名与同代预览；取消或关闭确认均不执行；取消执行不承诺回滚已发生的操作。
- 瞬时命令占用（另一个 mole 命令正在运行）视为可恢复状态：中性提示、可稍后重试，不显示为失败。
