# Task spec

## 背景

侧边栏仍含副标题、清理大小角标与状态圆点；四页的长列表或输出可把操作区推离视口。设置采用 grouped Form。蓝色焦点框来自用户反馈，源码阅读不能替代渲染复现。

本文件描述本 task 完成后的目标，当前状态仍为 backlog。

## 契约区

### 范围

- 移除侧边栏品牌副标题、清理大小角标和状态采样圆点；移除这些元素独占的 View 依赖，避免继续订阅无用状态。
- 导航按钮不绘制系统蓝色焦点框；保留键盘遍历、激活和可辨认的应用主题焦点样式，焦点态与选中态可区分。
- 安装包、优化、项目清理和历史页按可用视口布局：页头、必要提示和操作区保持可见，中间列表或输出占剩余空间并独立滚动。短内容按内容高度显示，不依靠任意固定像素高度挤压页面。
- 每个可滚动内容区域只有一个明确的滚动所有者。优化展开原始输出、项目清理长输出均受可用视口约束。
- 设置页底色使用 MoleTheme.background，保留表单分组和控件可读性。

### 非范围

- 扫描、确认、执行和状态功能开关的业务语义。
- 改变全部页面的信息架构。
