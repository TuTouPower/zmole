# Task spec

## 背景

`mo history --json` 可回答「mole 删过什么」。

## 契约区

### 范围

- `history --json --limit`（默认 20，范围 1–200）
- 列表展示会话摘要；无记录空态；失败态

### 非范围

- 改日志文件、撤销删除
