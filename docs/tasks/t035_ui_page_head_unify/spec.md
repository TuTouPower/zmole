## 契约区

### 范围

- 新建共享页面头组件：eyebrow（11pt 大写 accent 色）+ 页面标题（约 30–32pt 粗体）+ 副标题（12–13pt muted）+ 右侧动作区，对应 demo `.page-head` 结构。
- 五个页面接入该页头，动作按钮移入页头右侧动作区：
    - 卸载：刷新应用列表（含取消类进行中动作，按现有状态机语义）。
    - 磁盘：返回上级、再次分析。
    - 状态：暂停/恢复、刷新。
    - 历史：导出 JSON、刷新。
    - 设置：无动作按钮。
- 原位于窗口工具栏或页内工具条中、与上述重复的页面动作入口移除（进行中状态的取消按钮可保留在就近位置，不与页头按钮重复）。
- 更新 `docs/design/ui_contract.md`：页工具栏条目改为「页面动作位于页头右侧，进行中取消按钮可留在就近位置」。

### 非范围

- 不改各页内容区布局（状态页图表见 t037，历史页表格见 t038，磁盘列表见 t032）。
- 不改窗口标题栏与交通灯。
- 不改概览、清理、优化、项目清理、安装包 5 页的既有页头。
