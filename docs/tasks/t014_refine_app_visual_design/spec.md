# Task spec

## 背景

当前主窗口视觉层级与空间组织不一致，需建立紧凑、清晰的 macOS 工具界面，改善导航和信息阅读体验。

## 契约区

### 范围

- 主导航改为固定紧凑侧栏；各页面统一标题、操作层级、卡片、留白与青绿色强调色。
- 侧栏与页面在 880×620 和 1200×760 窗口尺寸下保持可读；支持浅色、深色及 zh-Hans、zh-Hant、en。
- 更新架构文档中与主导航实现相关的描述。

### 非范围

- 不改变清理、卸载、优化、预览、确认等业务语义与流程。
- 不增加新功能或更改 CLI、数据模型和持久化行为。
