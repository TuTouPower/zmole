# Task spec

## 背景

生产扫描 5000 个空目录返回 5001 层；4000 层限制仅在 ViewModel 接收整棵结果后生效。contentsOfDirectory 和 names.sorted 还会一次分配全部名称。目标是约束应用持有的扫描数据，同时保留完整目录访问和精确统计；限制每目录可见条目会造成浏览功能丢失。

本文件描述本 task 完成后的目标，当前状态仍为 backlog。

## 契约区

### 范围

- 使用 t052 唯一测量会话。统计完整性、可浏览数据与内存驻留分别管理；会话共享一个可注入条目预算，生产默认 4000，覆盖所有进行中测量及全部页面缓存，不是每个目录或每个 worker 各领 4000。
- 一个驻留记录包括文件/目录条目或摘要；records、childCache、在途结果和待发布批次合计计账，同一事实只保留一份主体。规范化路径和名称字节、枚举缓冲及发布队列另有可注入字节/队列上限，不能靠超长路径突破条目预算。
- 完整子项、精确硬链接身份和目录索引存入会话临时存储，驻留仅留有界工作集。目录枚举使用有界缓冲；不能先 contentsOfDirectory、全量 sorted 或全树构造再裁剪。深度遍历栈及去重集合在超出工作集时同样外存化，精确去重不换成近似算法。
- 大小统计继续完成，未驻留条目仍计入所属范围。磁盘临时存储有独立可注入空间上限；不足或写入失败时终结受影响测量并标明不完整，不发布部分合计为最终值，不损坏上次完成快照。
- 当前目录通过稳定排序的分页/按需加载访问全部直接子项。条目被淘汰后可以重新取得，搜索与排序面向完整目录，不能只搜索当前驻留页。目录行自身大小与父贡献保持 t052 语义。
- 对可见行分批发布且有背压，生产每批最多 100 条，测试可注入更小值；数据源允许时测量结束前发布首批，尾批按任务终态完成。刷新与取消同时取消枚举、存储和发布工作，释放会话资源。
- 会话临时存储只缓存派生只读事实；关闭会话后清理，异常退出的残留在下次启动清理，不引入跨启动目录结果兼容层。具体字节、深度和临时空间默认值由有界夹具测量确定并在实施笔记记录。

### 非范围

- 元数据预取、跨模块并发上限与概览迁移。
- 在预算耗尽后隐藏文件，或用不完整行小计替代完整目录合计。

- [ ] AC-012：会话临时空间耗尽或写入失败时，显示不完整或可重试错误，保留旧完整快照，不把部分数认证为最终值；取消和关闭后存储句柄及文件被释放。

## 上下文区

- 来源：无；2026-10-17 生产扫描器隔离复现 5001 层；源码入口 DiskScanner.list/walk、AnalyzeViewModel.apply。

### 有意不测

- 进程 RSS 包含系统及 Swift 运行时缓存，不以其等同于精确预算；应用管理数据的条目/字节/队列峰值必须自动断言，另记录一次实际 RSS 供诊断。
- 不操作真实跨卷挂载；设备边界用目录源替身验证。

### 测试策略

- 5000 目录、单层宽目录、深层路径、长名称及跨兄弟硬链接夹具分别验证预算与完整合计；三个任务并发验证共享计账。
- 用只允许逐批枚举的目录源断言首批在枚举结束前到达；主线程消费者阻塞时验证背压。
- DiskExplorerTests 中锁定“打开所有已测子层永不再读取”的两条测试整体替换为缓存命中、淘汰后按需恢复与 refresh 新世代测试，保留有效缓存复用意图，不承诺永不淘汰。
- 比较全部分页拼接结果与独立夹具目录清单，覆盖删除/新增后新世代、排序、搜索和临时存储故障。

### 未知契约清单

<!-- 规范（门禁必留，不得删除） -->

未核实的外部契约标为 `UNVERIFIED-BLOCKING` 或 `UNVERIFIED-SPIKE`；核实后改写为结论和验证方式。无则写“无”。

<!-- /规范 -->

- 会话临时存储后端及稳定分页 API：UNVERIFIED-SPIKE。执行期先用系统现有能力验证有界读写、排序/搜索、精确 inode 去重和取消清理，再确定后端；实验不阻止创建，不得在未核实前扩展新依赖。

### 风险与回退

- 风险：只限制结果层数会把名称数组、硬链接集合或发布队列留成无界旁路。所有应用持有工作集统一计账。
- 风险：把外存失败当成功会展示偏小最终值。错误与完成分开建模。
- 回退：撤回本 task 的存储与预算实现，丢弃会话临时数据；用户文件未被修改。

### 依赖与约束

- 依赖 t052 的会话所有权、统计身份与按需子项接口；为 t048 的全局并发及 t058 的命名子树统计提供有界后端。
- macOS 13+。存储选型复用系统能力与现有依赖，执行期先核实线程、分页及清理契约。
