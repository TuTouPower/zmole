# Task spec

## 背景

磁盘浏览用 `analyze --json`。第一版不提供删除。`--json` 必须在路径参数之前。

## 契约区

### 范围

- overview：`analyze --json`
- 下钻：点击目录 → `analyze --json <path>`，内容区换成该次结果的 entries
- 返回上级：再请求父路径或 overview，展示对应结果
- 加载/失败态；无删除按钮、无把选中项移到废纸篓的操作

### 非范围

- 交互 TUI、删除、外部卷专项（可后加路径入口但不删）
