# Task spec

## 背景

卸载页改为权威 demo 的列表加右侧详情，同时保留已经交付的真多选和批量卸载。列表 JSON 没有版本、最近使用和关联路径。

视觉权威只认 `docs/design/mole_desktop_demo_cn_final.html` 的 `renderUninstall`。不要用 `docs/design/demo_reference.html`。左列表、右详情、搜索和底部动作的位置照该函数。不退回该函数的单选交互。

## 契约区

### 范围

- 左列表、右详情。详情跟随当前焦点项。搜索只隐藏不匹配行，不清空已选。
- 保留多选与批量移入废纸篓。确认框绑定这次选中的 path 与 bundle id。
- 版本和最近使用从本机元数据读取，读不到显示未知。关联文件只显示该项 dry-run 结果，不编造。
- size 不能解析时显示未知，不显示 0。多选合计标明是应用本体估计，不加上关联文件体积，也不写成已释放空间。
- 行图标用系统应用图标。详情中的在 Finder 中显示打开该项真实 path。

### 非范围

- 不改卸载默认进废纸篓的行为，不加永久删除开关。
- 不从 list JSON 推断关联路径。
- 不做菜单栏常驻。
