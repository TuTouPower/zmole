# Task spec

## 背景

五类后台任务、三条概览 analyze 通道和磁盘测量可叠加；内部 worker 还会扩并发。问题机制存在，真实最优总名额尚未测量。目标是唯一资源准入与当前页优先，保留扫描服务的任务所有权；资源名额不再混入路径去重和结果缓存。

本文件描述本 task 完成后的目标，当前状态仍为 backlog。

## 契约区

### 范围

- App 装配唯一重扫描调度器，管理等待、优先级、准入、取消和执行名额；扫描服务持有逻辑任务与共享身份，调度器不缓存结果、不解释路径相同。
- 五类后台任务、每个概览探测、每次磁盘子树遍历均在实际执行前取得一个名额，含内部受管 worker 的完整生命周期才释放。每个逻辑遍历只申请一次，内部 worker 不再嵌套申请同一名额。
- 兼容任务共享由 t049/t052 的所有者完成，订阅者不重复申请名额；不同世代、权限或统计语义不因路径相同共享。t058 接入同一测量后端后仍按此身份规则，不保留专门禁止跨页面共享的分支。
- 当前页面的等待需求提升优先级；离页或解除需求后撤回提升。已执行任务不中断抢位。同级 FIFO；后台等待具有可注入防饥饿界限，到达界限获得下一可用位。后台同批起始顺序为卸载、安装包、clean、optimize、purge；不引入任意启动延时。
- 命令通道的可用性属于准入条件；不占名额等待另一个忙通道，不锁住正在使用的通道等待名额。扫描所有者仅提交已有可用执行器的作业，准入与启动之间没有额外资源等待；本 task 不改估算路径的固定分片策略。
- 排队取消或版本作废后立即移除，等待者收到确定终态；已运行取消须等全部扫描子任务退出才释放。新世代请求不能借旧世代已取消的名额登记假完成。
- status watch、轻量容量查询、目录首层有界列出及缓存 I/O 不占重扫描名额。破坏性执行仍受单写入租约及冲突扫描退出约束，不进入只读资源队列。
- 名额注入 1、2、3、4 验证正确性；生产默认值在完成代表性重复对照后选定，记录内部 worker 数、首批响应、总耗时、主线程、I/O 与内存，不声称一个外层名额等于一次文件系统 I/O。

### 非范围

- 重新实现扫描任务共享、结果版本、内存预算和元数据生命周期。
- 在名额不足时返回失败或取消正在执行的任务抢位。

- [x] AC-007：排队者不持名额；运行任务正常结束或全部子任务取消退出后，名额准确释放一次。
- [x] AC-009：磁盘测量排队期间主线程仍能完成已排队的界面更新。
- [x] [deploy] AC-010：名额 1、2、3、4 在相同代表性数据集上各至少重复 5 次、交错次序运行；记录首次遍历与预热遍历、首批响应/总耗时分布、内部 worker 数及可取得的资源指标，基于记录选择生产默认值。未测项说明限制，不能仅以单轮最小值决定。
- [x] AC-011：兼容共享任务只计一个名额；相同路径但不同统计语义、世代或权限的任务不错误合并，订阅取消不提前释放运行任务的名额。
- [x] AC-012：同批后台任务按固定起始次序进入执行，没有人为 sleep；空闲通道与名额同时可用才启动，名额为 1 和通道忙碌时均无死锁。
- [x] AC-013：排队后取消、失效或关闭会话的任务不启动；运行任务的元数据 worker 尚存活时名额不能交给下一项。

## 上下文区

- 来源：无；2026-10-17 核对独立通道、后台并发与子树窗口；t053 的受管 worker 和 t052 的共享身份是计账依据。

### 有意不测

- 不用假进程耗时决定生产默认值；无法取得的系统 I/O 指标明确未测，不伪造精确物理 I/O 上限。

### 测试策略

- 用一个总在途计数器观察三个服务实际入口，不只测试调度器内部计数；分别注入四种名额。
- 覆盖排队取消、在途取消、worker 延迟退出、通道忙、版本失效、优先级撤回及后台防饥饿。
- 共享任务两个消费者中一个退出不释放名额；不同硬链接上下文不得共享错误结果。
- 完成真实夹具重复对照后才写生产默认值和决策理由；测试以正确性与资源生命周期断言为主。

### 风险与回退

- 风险：按父进程退出就释放会漏掉实际 worker；使用完整受管生命周期。
- 风险：既占通道又等名额或嵌套取名额会死锁，统一准入且每逻辑遍历只取一次。
- 回退：撤回资源调度层；保留已有扫描所有权、版本及预算，不能回退出失管 worker。

### 依赖与约束

- 硬依赖 t049 的共享扫描所有者、t053 的受管进程生命周期、t056 的有界测量后端；t047/t052 经依赖链获得，不重复登记。
- t051 随后增加概览逐项领取与分段发布；本 task 仅在各条现有通道可执行的单次探测入口做准入，不让名额包住整片串行任务。
- macOS 13+；默认名额和防饥饿参数为内部策略，不新增用户配置面板。
