# Task spec

## 背景

隔离夹具复现了旧 worker 在等待任务组结束后不再检查队列：pending=1、worker=false、isScanning=true。当前子树合计还依赖调用方共享的 HardLinkDeduplicator：同一路径在新上下文返回 8192 字节，已计 inode 的上下文返回 0。祖先结果又会被较新的目录 listing generation 跳过。修复需要统一测量会话、明确结果身份和消费者派生，不能只在退出前补一次启动。

本文件描述本 task 完成后的目标，当前状态仍为 backlog。

## 契约区

### 范围

- 磁盘测量由一个会话级服务持有队列、在途任务与扫描世代，ViewModel 只负责浏览需求和展示。队列非空就保持消费；补位、取消和退出检查由同一状态所有者串行决策。
- 测量事实与消费者去重贡献分开：同一快照内文件身份为 device+inode，记录分配块；文件行可显示自身大小，父合计按所属统计范围精确去重。同一路径在不同父统计范围的贡献不能直接互换。
- 目录自身去重合计与其对父范围的贡献有明确名称和独立字段。兄弟间共享 inode 的贡献归属按规范化路径排序确定，不随 worker 完成先后改变；父合计不能简单相加可能重叠的目录自身合计。
- 共享身份至少包含测量根、扫描世代、统计语义、设备/权限边界。只有相同身份的任务可复用；纯路径相同不够。消费者独立派生所需范围，取消一个消费者不破坏其他消费者仍需的任务。
- 进入正在测量的祖先下的目录，仍列当前层；订阅同一兼容会话中的事实与终态，不重复遍历已覆盖子树。祖先完成后，当前层、展开层与父列表均得到正确大小或不可读状态，不能被较新的 listing generation 永久挡住。
- 重新分析创建新世代并替换当前子树需求；旧世代结果不得发布到新世代。取消清空相应需求，移除排队项并等待实际遍历退出，终态不留下假忙碌。
- 提供同一会话的目录摘要与直接子项访问边界，供 t056 实现统一内存预算、t058 取得命名子树合计；不在 ViewModel 再建立一份独立事实真相。

### 非范围

- 跨模块并发策略、属性预取与概览展示迁移。
- t056 的驻留预算与分页 UI，但服务接口必须允许按需取得子项，不能要求一次返回整棵树。

只写可观察、可独立验证的行为；每条使用稳定且不复用的 `AC-NNN`。需真实部署或人工环境验证时在编号前加 `[deploy]`。技术选型不作为行为 AC。

- [ ] AC-001：测量进行中新入队任务会被继续消费；待测和在途都为空时 isScanning=false。
- [ ] AC-002：任务组已取空旧队列后再入队，worker 结束时不会留下队列非空且无消费者的状态。
- [ ] AC-003：取消后旧需求不再启动，实际遍历退出后 isScanning=false；已取消世代的迟到结果不发布。
- [ ] AC-004：祖先测量中进入子目录不重复测量已覆盖子树；完成后父列表里的子目录行有正确大小或不可读；无关目录仍会测量。
- [ ] AC-005：同一路径在含共享硬链接的两个统计范围中，目录自身合计一致，父范围去重贡献各自正确；逆转 worker 完成顺序不改变结果。
- [ ] AC-006：祖先测量开始后才列出的当前层及展开层，祖先完成后全部等待行进入正确终态，不因 listing generation 较新永久计算中。
- [ ] AC-007：旧世代被阻塞时重新分析，再放行旧结果，页面只接受新世代；相同路径但不同世代不共享旧结果。
- [ ] AC-008：两个兼容消费者复用一次遍历；一个解除需求不影响另一个完成，最后一个需求取消后没有遗留遍历。
- [ ] AC-009：符号链接只计自身、跨设备不计入父合计、硬链接在同一统计范围只计一次；未知、取消和不可读均不伪装成 0 或完整合计。

### 风险与回退

- 风险：把父贡献存成目录自身大小会在导航、共享或并发顺序变化后错算。两种值分别命名、分别测试。
- 风险：新旧所有者同时存在会重复启动任务。执行收尾移除旧 ViewModel worker 与重复缓存权威。
- 回退：撤回本 task 的会话服务与装配；会话测量数据可丢弃，用户文件只读。

### 依赖与约束

- 无硬依赖。为 t056 提供统一会话及统计身份；全局名额由后续 t048 接入。
- macOS 13+，不调用 mole，不在 Feature View 中直接读取文件系统。
