# Task spec

## 背景

磁盘测量逐项取状态属实，但属性预取是否更快尚未证实。预算与概览统一后，优化必须验证最终共用后端的实际枚举路径，不能凭单夹具各测一次或不同缓存状态决定生产方案。

本文件描述本 task 完成后的目标，当前状态仍为 backlog。

## 契约区

### 范围

- 在 t058 最终统一测量后端上比较逐项状态读取与枚举预取；复用相同统计、会话、预算和取消实现，只替换元数据读取适配器，实验结束后生产保留一种读取方式。
- 先验证分配块、符号链接不跟随、硬链接身份与去重、设备边界、不可读/消失条目及取消语义一致；预取缺失必要字段时可在同一策略内定向补取，但统计成本必须计入。
- 代表性临时数据包含宽目录、深目录、大量小文件、稀疏文件、硬链接及混合权限。每种方式、每种场景至少重复 10 次，AB/BA 交错次序；区分新夹具首次遍历与重复预热，不声称主动清空了 OS 缓存。
- 记录总耗时与首批延迟分布、元数据调用量、驻留预算、主线程和可取得 I/O 指标。只有语义通过且代表性结果稳定改善、无关键场景明显退化时才采用预取；证据不充分则保留逐项读取，并删除未采用的生产候选路径。
- 实验材料可放 spike；目标是有证据的最终选择，不预设 API、提速倍数或必须修改生产枚举。

### 非范围

- 另建测量引擎、改变预算/名额、削弱目录完整浏览或引入运行时双后端切换。
- 用单轮最小值、假 I/O 或源码调用名作为性能收益证据。

## 上下文区

- 来源：无；2026-10-17 审阅将属性预取认定为待验证优化，未取得产品收益证据。

### 有意不测

- 不测真实用户目录、全盘冷缓存或真实跨卷挂载；这些限制写入实验结果，不宣称泛化到所有磁盘。

### 测试策略

- 两种读取复用统一统计测试集，含稀疏文件、跨范围硬链接、悬空链接、取消与权限/消失竞态。
- 测量实际生产枚举入口，而不是孤立 API 微基准；补取、排序、索引与批次成本包含在内。
- 在隔离实验目录记录每次原始指标与汇总分布；未采用实现不进入长期生产路径。

### 未知契约清单

未核实的外部契约标为 `UNVERIFIED-BLOCKING` 或 `UNVERIFIED-SPIKE`；核实后改写为结论和验证方式。无则写“无”。

- 元数据预取 API 的实际字段完整性、链接语义及收益：经 spike s002 与 10 轮 AB/BA 测量核实，Foundation URL 预取存在 338% 的显著性能退化（URL 对象分配与字典桥接开销过高），且未消除精确块与 inode 的查询开销。结论：生产保持逐项 lstat 读取（见 d002、s002）。

### 风险与回退

- 风险：重复实验被缓存或次序偏置误导，使用多场景交错次序并报告分布。
- 风险：预取省调用却换掉大小/链接语义，正确性验证优先于性能。
- 回退：最终选择逐项读取；预算、会话及调度不变，实验失败也是有效结论。

### 依赖与约束

- 依赖 t058，保证实验覆盖磁盘与概览最终共用后端；t056/t048 经依赖链获得。
- macOS 13+，只读实验，不增加用户设置或长期兼容分支。
