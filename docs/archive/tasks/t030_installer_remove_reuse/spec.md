# Task spec

## 背景

安装包页每次删除一个文件，捆绑 `installer --remove` 都会重新遍历全部扫描根，再判断目标是否仍在候选里。批量删除 N 个文件就会扫描 N 次。

用户已确认（2026-10-17）：页面会话内复用当前名单。删除时只复核那一个文件的大小和 identity。路径不在名单里、大小变了或 identity 变了，拒绝删除并保留原文件。

## 契约区

### 范围

- 同一次名单在该页面会话内复用，直到用户重新扫描或名单被写入操作作废。
- 删除某个已列出文件时，只检查该路径自身：它是名单中的那一项，当前大小和 identity 与名单记录一致。
- 删除过程不遍历扫描根，不读取名单以外的目录。
- 路径不在当前名单中、大小不一致或 identity 不一致时，拒绝删除，原文件保留。
- 批量删除沿用同一份名单，每个文件单独复核，仍然一次失败不影响其他文件的原有失败报告。
- 没有用户确认时不删除。

### 非范围

- 不改变安装包扫描根、深度和 zip 判断规则。
- 不把安装包扫描放进空闲预跑。那是 t031。
- 不改删除去向：仍然移入废纸篓，失败不退回永久删除。
- 不改磁盘页和卸载页。
