# p018 设置中增加关闭状态界面与状态监控功能的开关

- 来源：用户 2026-10-17 口述
- 内容：在设置页（`src/zmole/Features/Settings/SettingsView.swift`）增加功能开关，允许用户彻底关闭「状态」界面及后台状态监控：
    1. **设置持久化开关**：新增 `@AppStorage`（如 `statusFeatureEnabled`，默认开启），在系统设置区块提供对应 Toggle 与说明文案。
    2. **导航与侧边栏联动**：当开关关闭时，侧边栏（`AppDestination` / `NavigationModel`）隐藏或禁用「状态」导航项；若当前停留在状态页，自动跳转到概览页。
    3. **后台监控流停用**：开关关闭时停止或不启动 `StatusWatchService` / `status-go` 监控进程流，避免不必要的系统开销。
- 边界：关闭仅影响状态页及其专属后台流，不破坏概览页的系统概要采样（若概览复用状态数据，需按不可用安全回退，不得导致概览崩溃）。
