## 布局与组件

- 默认窗口 1200 × 780 pt，最小 1100 × 700 pt；系统标题栏和交通灯，内容区不绘制交通灯。
- 侧边栏两个分组共十个目的地：工作区（概览、清理、卸载、磁盘、优化、状态、项目清理、安装包）、系统（历史、设置）。启动进入概览；系统菜单的设置打开侧边栏设置页。
- ⌘K 与标题栏搜索只按页面名称跳转，面板内不得出现清理、卸载、优化、项目清理或安装包执行动作。
- 颜色、圆角、间距、字号按视觉权威的 CSS 变量落到浅色与深色；图标用 SF Symbols；侧边栏品牌为 zmole 与本地化的产品副标题。
- 页面动作位于页头右侧（标题 + 副标题 + 动作区，无 eyebrow 小字）；进行中的取消按钮可留在就近位置；预览、取消、确认或批量选择条固定在工作区上方，内容独立滚动。
- 基础间距 4/8/12/16/24 pt；标准行约 52 pt、应用行约 62 pt、进程表约 34 pt。
- 正文约 13 pt，区块标题约 14–17 pt；路径使用等宽字体，数值使用等宽数字。重要信息不依赖小于 11 pt 的文字。
- 使用系统语义背景、细分隔线和中性面板。蓝色（与应用图标一致的蓝系）作为选择、安全预览动作与成功状态；红色用于实际危险操作或失败。
- 圆角按控件、分组分别使用约 6–8 和 10–12 pt；阴影仅用于系统浮层。
- 原生键盘焦点、可访问名称、禁用原因和浅深色对比必须可辨。悬停不得是唯一操作入口。

## 页面契约

|页面|结构|数据与交互要求|
|---|---|---|
|概览|页头动作、健康环、存储估算卡、最近活动、系统状态四宫格（四卡同一固定高度）|真实 status 采样与本地目录估算；快捷卡片与趋势条已移除；刷新触发重采样、清理入口跳转清理页；采样不足或数据缺失显示占位不伪造；估算进入页面即扫描、不依赖采样；部分结果展示并落盘、缺失段占位并标「估算不完整」；被取消的扫描不落盘|
|卸载|左列表、右详情、多选操作条|真多选；搜索只过滤显示不清空选择；列表先出名单、大小与图标随后补上，大小未知不可记零；版本/最近使用来自本次扫描结果；关联路径只来自该项 dry-run；确认绑定完整批次，确认前只核对路径与 bundle id；打开页面显示后台预跑结果与扫描时间|
|清理|本次预览摘要、分类与路径列表、保护规则侧栏|分类只读展开；估计空间与实际结果分开；说明执行重扫与移入废纸篓；保存保护规则使旧预览失效；不按勾选子集执行；扫描显示当前阶段名不显示百分比；打开页面直接显示后台预跑预览与扫描时间|
|优化|页头、说明条、只读任务行、预览输出|任务来自 mole dry-run，行不可切换；跳过原因显示在对应行；会删除文件的任务标永久删除；执行范围不由界面裁剪；打开页面直接显示后台预跑结果与扫描时间|
|项目清理|页头、说明条、预览输出、扫描目录编辑入口|执行 `purge --yes`，范围由 mole 决定，非勾选子集；扫描目录编辑 `~/.config/mole/purge_paths`；删除为永久删除并写明；打开页面直接显示后台预跑结果与扫描时间|
|状态|指标卡、磁盘容量、进程表、趋势、暂停|真实 watch 数据；首帧待采样；暂停与离页停止；旧数据显式标记；采样不足不伪造趋势|
|安装包|说明、扫描结果、多选、预览确认后移除|非交互接口列出并移除；移除走废纸篓；只接受本次预览中的绝对路径，删除只复核目标自身不重扫扫描根；页面会话内复用名单；打开页面直接显示后台预跑结果与扫描时间|
|历史|操作记录列表、导出 JSON 按钮|数据来自 `history --json`；空记录显示空状态；导出把本次 JSON 原样写入用户选择的文件|
|设置|语言、外观、登录项、项目扫描目录、两份白名单、CLI 行、关于|语言/外观跟随或覆盖并持久化；登录项失败显示原因且不假装开启；clean 白名单为路径、optimize 白名单为任务 id；项目扫描目录复用项目清理编辑器；CLI 行显示捆绑 SOURCE_VERSION tag 与路径；不做菜单栏常驻；不提供“移除前检查”“包含浏览器缓存”开关|

## 操作状态

所有破坏性流程可观察地覆盖：未预览、预览中、预览成功、预览过期、确认、执行中、取消中、成功、失败、部分完成、取消和结果未知。

预览完成后显示本次影响范围，确认 sheet 使用具体动作名和同代预览。取消或关闭确认均不执行。取消执行不承诺回滚已经发生的操作。失败和部分完成使用持久结果区，不能只显示瞬时提示。

瞬时命令占用（另一个 mole 命令正在运行）属于可恢复状态：以中性提示展示并允许稍后重试，不得显示为失败；只有真实错误才进入持久失败结果区。

多选卸载总大小标为应用本体估计大小；不能与关联数据或已释放量混用。CLI 输出无法证明逐项成功时显示未知和原文摘要。

## 可重复视觉验收

演示入口必须用注入的假服务驱动生产 View，不能维护另一套展示页面。演示状态覆盖普通数据、长名称与路径、未知大小、空结果、处理中、失败、取消、预览失效和部分完成，且不能执行真实 mole 命令。

验收矩阵：

|维度|检查|
|---|---|
|尺寸|1200 × 780、1100 × 700；主要动作可见，无水平裁切|
|外观|浅色与深色；分隔、选中、焦点、危险动作均可辨|
|语言|简体、繁体、英文；长标签不重叠，不截掉关键动作|
|软件|多选条不遮列表；列语义一致；展开不改变选中；筛选不丢选择|
|分析|详情不遮地图；面积比例正确；小矩形仍可从列表访问|
|状态|暂停、断流、恢复、首帧和陈旧进程数据均有明确表达|
|交互|Tab/方向键/回车/Escape 可完成主要路径；VoiceOver 能读出名称、数值和选择状态|

交付实际运行 App 截图，并与参考和本基线逐页比较。编译、单测及 SwiftUI Preview 不能代替视觉验收。视觉证据尚未形成前，不声明界面改版完成。
